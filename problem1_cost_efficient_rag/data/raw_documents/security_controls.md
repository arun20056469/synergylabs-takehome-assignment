# Security controls

AuroraDesk encrypts customer data in transit with TLS 1.2 or higher and at rest with AES-256. Production access requires multi-factor authentication and is granted using least-privilege roles. Security logs are retained for 365 days. Customers can request a copy of their data through the privacy portal.

The incident response target is to acknowledge a confirmed severity-one incident within 30 minutes. The security team publishes a post-incident summary for material customer-impacting events.
